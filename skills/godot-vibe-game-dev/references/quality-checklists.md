# Godot 游戏验收清单

只读取和当前任务有关的部分。清单用于发现回归，不要求每次修改都执行完整发布测试。

## 项目与运行

- 主场景存在，项目可以启动。
- 没有 GDScript 解析错误或把警告当错误导致的失败。
- 输入动作存在，键盘和鼠标触发符合界面说明。
- 自动加载脚本依赖顺序正确。

## 玩家与动画

- 待机、移动、跳跃、射击、受击、换武器和死亡是同一角色。
- 每组帧的视觉高度、脚底基线、朝向和缩放一致。
- 鼠标跨过角色时朝向稳定，枪口和弹道方向一致。
- 临时动作结束后能恢复，不会永久停留在受击或射击帧。
- 角色落地时贴合地面，不悬空或陷入地面。

## 武器与弹丸

- 切换武器同步更新数值、人物表现、枪口、HUD和音效。
- 半自动和全自动输入行为正确。
- 弹丸有合理尺寸、速度、朝向、命中效果和生命周期。
- 手雷具有投掷轨迹、引信、爆炸范围和视觉反馈。
- 未解锁武器不能被错误切换；拾取后可以使用。

## 敌人与Boss

- 侦测、追击、停止和攻击范围不会在边界反复切换。
- 受击状态按时退出；死亡后停止AI、伤害和碰撞。
- 血条跟随主体、比例正确，并在死亡时隐藏。
- 炮塔、坦克、直升机和Boss的残骸或爆炸位于合理位置。
- 远距离敌人不会无意义抖动、隔墙攻击或在屏外持续输出。

## 关卡与碰撞

- 主路线可完成，不存在必须借助失效碰撞体才能通过的地点。
- 沙包、平台和地形分别测试走过、跳上、下落和从下方通过。
- 装饰物不阻挡玩家，交互物和伤害物使用正确碰撞层。
- 撤离点、任务门和Boss触发器只在正确任务阶段开放。
- 场景物件贴合地面，背景与前景层级正确。

## 画面与UI

- 精灵透明背景，无白底、白边、残留文字和裁切错误。
- 背景无灰条、拉伸、明显接缝或突然跳变。
- HUD在支持分辨率下不重叠、不超出屏幕、不遮挡核心战斗。
- 文案语言一致，长文本能完整显示。
- 像素游戏保持最近邻过滤和整数像素对齐。

## 音频

- 背景音乐可循环且不过度压制音效。
- 射击、命中、受击、爆炸和拾取在正确时机播放。
- 音频不会因每帧触发而堆叠爆音。
- 暂停、切换场景和返回菜单时音频状态正确。

## 发布

- 运行目标平台的最终构建，而不只运行编辑器版本。
- 构建包包含启动文件、数据包、操作说明和必要许可。
- 新目录解压后可以启动，不依赖开发机绝对路径。
- 仓库忽略引擎缓存、构建产物、临时截图和个人文件。
- README标明版本、运行方式、试玩版边界和反馈入口。
