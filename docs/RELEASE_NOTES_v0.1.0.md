## 钢铁突围：前线行动 v0.1.0

首个公开 Windows x64 开发试玩版，包含两张连续地图：森林前线和装甲堡垒。

### 试玩内容

- 鼠标指向瞄准，键鼠横版射击。
- 手枪、突击步枪、手雷，以及关卡内可拾取的 RPG、霰弹枪和狙击步枪。
- 步兵、投弹兵、炮塔、直升机、坦克与重装机甲战斗。
- 通信塔、守门坦克、装甲指挥车及撤离目标。
- 中文界面、音乐与射击/受击/爆炸音效。

### 下载运行

下载 `SteelBreakout-v0.1.0-Windows-x64.zip` 后完整解压，双击 `SteelBreakout.exe`。无需安装 Godot。请保持 EXE 与 PCK 文件在同一目录。

目标平台为 Windows 10/11 64 位，需要支持 OpenGL 3.3 的显卡。本包没有商业代码签名，Windows 可能提示未知发布者；请从本发布页下载并核对 `SHA256SUMS.txt`。

### 已知边界

这是开发试玩版，部分图集边缘、动画衔接、物件对齐与战斗平衡仍在迭代。当前两关共用背景音乐，部分武器复用音效；尚无手柄支持、按键自定义和即时位置存档。

操作表、源码构建方式、素材与第三方许可说明见仓库 README。
